# Лабораторна робота 1. Розробка статичного інтерфейсу Web-додатка
## Галактіонова Антоніна Юріївна, КВ-31  

### Завдання
Розробити статичні Web-сторінки додатку та перевірити коректне їх відображення на екранах різного розміру.

### Опис додатку
SurveyApp — легка та проста платформа для створення опитувань. Надає можливість авторизуватися в додатку, створювати опитування та переглядати їх результати.
